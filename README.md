SAAS TIENDA ROPA

Aplicacion de full-stack tipo SaaS pa gestion de tienda de ropa.

### Las tegnologias
- React / Vite
- NestJS
- PostgreSQL
- TurboRepo (Monorepo)
- JWT Authentication

### Estuctura

apps/
- web → frontend
- api → backend

packages/
- hooks
- ui

### Funcionalidades

- Registro e inicio de sesión (JWT)
- Dashboard
- Gestión de productos
- Conexión a base de datos PostgreSQL

### Instalación

// bash
pnpm install
pnpm dev
